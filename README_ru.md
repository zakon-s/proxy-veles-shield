# 🛡️ Veles Proxy

> **Современная платформа умной маршрутизации и защиты трафика для роутеров на базе OpenWrt и ImmortalWrt.**  
> Позволяет настроить обход блокировок для всей домашней сети без необходимости ставить VPN на каждый телефон, телевизор или компьютер.

## ⚡ Быстрая установка в одну команду

Подключитесь к роутеру по **SSH** (через PuTTY, Termius или стандартный терминал) и выполните:

```bash
wget -qO- [https://raw.githubusercontent.com/zakon-s/proxy-veles-shield/master/install.sh](https://raw.githubusercontent.com/zakon-s/proxy-veles-shield/master/install.sh) | sh
