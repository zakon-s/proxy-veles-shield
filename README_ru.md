# 🛡️ Veles Proxy

> **Интеллектуальная система централизованной маршрутизации и защиты трафика для роутеров под управлением OpenWrt / ImmortalWrt.**  
> Разворачивает прозрачный обход блокировок на уровне всей домашней сети: телевизоры, приставки, смартфоны и ПК работают без установки сторонних VPN-клиентов.

## 💡 Зачем это нужно?

Вместо того чтобы вручную настраивать и включать VPN на каждом смартфоне, ноутбуке или Android TV, **Veles Proxy** берет фильтрацию трафика на себя прямо на шлюзе:

* **Умное разделение (Split Tunneling):** Государственные сервисы (Госуслуги), российские банки, маркетплейсы и онлайн-кинотеатры идут напрямую через домашнего провайдера на полной скорости тарифа.
* **Автоматический обход:** Заблокированные ресурсы, зарубежные нейросети и закрытые сервисы прозрачно уходят в зашифрованный туннель.
* **Экономия трафика VPS:** Для тяжелого медиа-трафика (YouTube 4K, Discord) в связку интегрированы локальные средства обхода DPI без нагрузки на удалённый сервер.

## ⚡ Быстрая установка

Подключитесь к роутеру по **SSH** (через PuTTY, Termius или стандартную консоль `ssh root@192.168.1.1`) и выполните команду:

```bash
wget -qO- [https://raw.githubusercontent.com/zakon-s/proxy-veles-shield/master/install.sh](https://raw.githubusercontent.com/zakon-s/proxy-veles-shield/master/install.sh) | sh
```

### Что делает установщик:
1. Автоматически распознает архитектуру процессора (`aarch64`, `mips`, `x86_64`) и формат пакетного менеджера (`opkg` или `apk`).
2. Разворачивает веб-интерфейс **Veles Proxy** на русском языке в LuCI.
3. Скачивает и конфигурирует выбранное ядро маршрутизации.
4. Опционально разворачивает стек локального противодействия DPI (**Zapret 2** + **ByeDPI**).
5. Создает базовый набор правил маршрутизации под юрисдикцию РФ.

## ⚙️ Сравнение ядер

Установщик предлагает выбор между двумя ядрами в зависимости от объема флеш-памяти роутера:

| Параметр | `hiddify-core` (По умолчанию) | `sing-box-extended` |
| :--- | :--- | :--- |
| **Размер на диске** | ~15–20 МБ (Компактное) | ~75–80 МБ (Полное) |
| **Рекомендуемая память** | Роутеры с флешкой 32–64 МБ | Роутеры со 128+ МБ / U-Boot mod |
| **Поддерживаемые протоколы** | VLESS (Reality), VMess, Trojan, ShadowTLS, Hysteria 2, TUIC | VLESS, VMess, Trojan, ShadowTLS, Hysteria 2, TUIC + **AmneziaWG**, **WARP** |
| **Потребление RAM** | Минимальное | Стандартное |

## 🚀 Первоначальная настройка

1. **Вход в панель:**  
   Откройте браузер по адресу `http://192.168.1.1` ➔ перейдите в раздел **«Службы»** ➔ **«Veles Proxy»**.

2. **Добавление узлов:**  
   * Перейдите во вкладку **«Настройки узлов»** ➔ подраздел **«Подписки»**.
   * Вставьте ссылку на подписку формата VLESS / Sing-box / Base64.
   * Нажмите **«Сохранить и применить»**, затем **«Обновить подписку»**.

3. **Выбор режима:**  
   * Во вкладке **«Настройки клиента»** в пункте **Основной узел** выберите конкретную страну или группу **`URLTest`** (автоматический выбор ноды с минимальной задержкой).
   * Убедитесь, что переключатель службы переведен в статус **«Включено»**.

## 🛠️ Архитектура и сценарии работы

```text
[ Клиент: ТВ / Телефон / ПК ]
             │
             ▼
      [ Veles Proxy ]
             │
   ┌─────────┴─────────┐
   ▼                   ▼
(Домен в РФ?)     (Заблокирован?)
   │                   │
   ▼                   ▼
[ Прямой выход ]   [ Туннель Veles ] ──► (VPS: DE / NL / US)
(Банки, Видео)     (VLESS Reality)
```

* **Режим Re:filter:** Маршрутизация по встроенным базам доменов (`geosite:category-ru` пускается мимо прокси, всё остальное фильтруется согласно правилам).
* **Связка с Zapret 2:** Если зарубежный сервер перегружен, пакетный модификатор `nfqws` на уровне ядра системы разбирает сигнатуры пакетов и восстанавливает прямой доступ к YouTube и голосовым каналам Discord без участия туннеля.

## 📋 Полезные консольные команды

Проверка состояния службы:
```bash
/etc/init.d/homeproxy status
```

Быстрый перезапуск демона:
```bash
/etc/init.d/homeproxy restart
```

Проверка свободного места в разделе постоянной памяти:
```bash
df -h /overlay
```

Чтение актуального журнала маршрутизации и ошибок:
```bash
logread -e homeproxy
```

Полная очистка временных пакетов и кэша:
```bash
apk cache clean 2>/dev/null || rm -rf /tmp/opkg-lists/*
```

## 📌 Системные требования

* **Поддерживаемые платформы:** MediaTek Filogic (MT7981, MT7986, MT7988), Qualcomm, Rockchip, x86_64.
* **Операционная система:** OpenWrt 23.05, 24.10, 25.12 или ImmortalWrt любой свежей версии.
* **Свободное место `/overlay`:** 
  * от **25 МБ** для варианта с `hiddify-core`.
  * от **90 МБ** для варианта с `sing-box-extended`.
